Проект посвящён задаче бинарной классификации электронных писем на спам и не спам с использованием методов машинного обучения.
В качестве основной модели используется Random Forest, а также применяются техники подбора гиперпараметров, оценки качества и визуализации результатов.

🧠 Цель проекта
Целью проекта является:
построение эффективной модели классификации спам-сообщений
анализ качества модели с использованием современных метрик
интерпретация результатов и важных признаков
Задача имеет практическое применение в фильтрации электронной почты, антиспам-системах и информационной безопасности.

📊 Датасет
Используется Spambase Dataset из репозитория UCI Machine Learning Repository.
Источник: UCI ML Repository
Количество объектов: 4601
Количество признаков: 57
Целевая переменная: spam
1 — спам
0 — не спам
Типы признаков:
частоты слов (word_freq_*)
частоты специальных символов (char_freq_*)
статистики заглавных букв (capital_run_length_*)
Датасет хорошо подходит для классических ML-алгоритмов и часто используется как эталонный в задачах фильтрации спама.

🏗️ Этапы работы
1. Загрузка и подготовка данных
загрузка датасета по URL
задание имён столбцов
разделение признаков и целевой переменной
2. Разделение выборки
Данные разделяются на:
80% — обучающая выборка
20% — тестовая выборка
Используется stratify=y для сохранения пропорций классов.
3. Построение модели
В качестве основной модели выбран RandomForestClassifier, так как:
он устойчив к шуму
не требует масштабирования признаков
хорошо работает с нелинейными зависимостями
Дополнительно используется:
class_weight='balanced' — для учёта дисбаланса классов
5. Подбор гиперпараметров
Для оптимизации модели применяется GridSearchCV.
Подбираемые параметры:
n_estimators — количество деревьев
max_depth — максимальная глубина дерева
min_samples_split — минимальное число объектов для разбиения
Кросс-валидация:
cv = 5
метрика оптимизации: F1-score
5. Оценка качества модели
Используются следующие метрики:
Accuracy
Precision / Recall / F1-score
ROC AUC
Confusion Matrix
Также строится:
ROC-кривая
График важности признаков

🧩 Важность признаков
Random Forest позволяет оценить вклад каждого признака в итоговое решение.
Наиболее значимыми оказались:
частоты слов, характерных для спама
частоты специальных символов
статистики заглавных букв
Это подтверждает интерпретируемость модели и корректность выбранного подхода.

Для детального анализа качества модели использовалась матрица ошибок (Confusion Matrix), позволяющая оценить количество ложных срабатываний и пропущенного спама.
Модель демонстрирует низкое количество ложных блокировок (False Positive), что особенно важно для почтовых систем, где потеря легитимных сообщений критична.
